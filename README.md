# Figure Craft

Next.js landing page for a 3D collectible figure studio.

## Run

```bash
npm install
npm run dev
```

## Images

Drop product photos into `public/images/` with these names and they replace the placeholders automatically:

- `hero.png` — hero figure (transparent background works best)
- `xenomorph.png`, `alien-egg.png`, `facehugger.png` — collection cards
